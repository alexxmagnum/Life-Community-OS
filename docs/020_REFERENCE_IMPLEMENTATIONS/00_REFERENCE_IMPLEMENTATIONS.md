# Purpose

This document defines the official Reference Implementation Architecture of Life Community OS.

Reference Implementations establish the canonical implementation patterns for every Platform Capability while preserving Business Behaviour, Platform Stability and architectural consistency.

Reference Implementations are implementation guides.

Architecture remains the source of truth.

---

# Question this document answers

> How should Platform Capabilities be implemented?

---

# Scope

This document defines:

- implementation standards;
- implementation contracts;
- reference templates;
- engineering guidelines;
- governance.

It does not define:

- business requirements;
- architecture principles;
- project planning;
- sprint planning.

---

# Definition

A Reference Implementation defines the official way to implement Platform Capabilities.

Every implementation should follow these standards.

---

# Objectives

Reference Implementations exist to:

- standardize implementation;
- maximize code reuse;
- reduce implementation variability;
- improve maintainability;
- simplify onboarding;
- support long-term scalability.
