# Purpose

This document defines the standard output format used by every Engineering Agent inside Life Community OS.

Every deliverable should be predictable, consistent and reviewable.

Consistency improves collaboration.

Standardization improves engineering.

Regardless of specialization, every Agent communicates using the same engineering standards.
