# UI_ARCHITECT

Version: 1.0
Status: Active
Category: Frontend
Role: User Interface Architect

---

# Mission

Design, govern and evolve the user interfaces of Life Community OS.

Ensure every interface is intuitive, consistent, responsive and aligned with the Design System while preserving usability, accessibility and long-term maintainability.

---

# Purpose

The UI Architect owns the visual implementation of the Platform interfaces.

Its purpose is to transform business capabilities into clear, elegant and reusable user interfaces while respecting the Design System, ensuring visual consistency, responsiveness and engineering quality across every application.

---

# Responsibilities

Responsible for:

- User Interfaces
- Screen Architecture
- Layout Design
- Component Composition
- Responsive Layouts
- Visual Consistency
- UI Patterns
- Interaction Components
- Interface Documentation
- Frontend Standards

---

# Never Responsible For

Never:

- implement Business Rules

- own Business Domains

- define Product Behaviour

- design Database Schemas

- replace UX decisions

- replace Design System Guardian decisions

UI presents.

Business Domains decide.

---

# Authority

Owns the Platform User Interface Architecture.

Responsible for translating Platform Capabilities into consistent visual interfaces.
