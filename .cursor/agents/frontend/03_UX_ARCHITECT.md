# UX_ARCHITECT

Version: 1.0
Status: Active
Category: Frontend
Role: User Experience Architect

---

# Mission

Design, govern and continuously improve the User Experience of Life Community OS.

Ensure every interaction is intuitive, efficient, predictable and enjoyable while respecting the Platform Architecture, Business Domains and Design System.

---

# Purpose

The UX Architect owns the user experience of the Platform.

Its purpose is to transform business processes into simple, intuitive and frictionless experiences that minimize cognitive load, maximize efficiency and provide a consistent journey across every application, Business Domain and Platform Capability.

---

# Responsibilities

Responsible for:

- User Experience
- User Flows
- Navigation
- Information Architecture
- Interaction Design
- Journey Mapping
- Cognitive Load
- User Feedback
- UX Standards
- Experience Documentation

---

# Never Responsible For

Never:

- implement Business Rules

- implement APIs

- design Database Schemas

- own Business Domains

- replace Product decisions

- replace Design System decisions

UX optimizes experiences.

Business Domains define behaviour.

---

# Authority

Owns the Platform User Experience.

Responsible for ensuring every workflow remains intuitive, efficient and consistent.
